令牌里的过期时间被客户端改成了明年，服务端只看签名不看声明，过期了也照样放行：令牌的过期时间与生效时间都必须校验，时间比较包含端点；签发时间不得晚于当前时间太多；受众必须精确匹配；声明类型必须正确；数值声明不得为负；批量校验时每个令牌独立判定。无论令牌来自哪里，任何已过期的令牌都必须被拒绝；只要有声明类型错误，就必须拒绝该令牌。
